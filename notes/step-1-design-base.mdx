這是重建的視覺基座：實際打包進擴充功能的 Noto Sans TC / Noto Sans / Noto Sans Mono（子集 woff2），以及 README Design Tokens 的色彩、圓角、陰影、元件雛形。後續 A–E 各狀態都會引用這裡的 token，不再自行調色，作為整套介面的共同基準。

## 字體

CJK 用 Noto Sans TC（700 主字／500 標籤／400 內文），元素描述、尺寸、檔名用 Noto Sans Mono。使用者動態文字（描述、檔名）皆為 ASCII，故 TC 只需子集固定介面字。

## 選取覆蓋框（A 狀態預覽）

A1 hover：藍色虛線 + 外圈輔助線 + 藍標籤。A2 鎖定：金色實線 + 柔光暈 + 金標籤 + 右下尺寸標籤。實作會用行進虛線動畫，keyframes 保留四軸 100% 錨點。

## 深色網頁上的自足卡片

深底時卡片加 1px 白色外描邊、陰影換 `0 14px 34px rgba(0,0,0,.45)`，確保浮動卡片在任意背景都可讀。
